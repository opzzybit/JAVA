        [5.6].  Compare and contrast the "while" and "for" iteration statement 
        
        Ans:    the "for" iteration statement is a counter control statement ,
                the "while" iteration statement is a sentinel control statement.
                
                THE COUNTER CONTROL STATEMENT control the number of times your loop 
                will run before it stops.
                THE SENTINEL CONTROL STATEMENT  is just like a key which when it opened the door 
                way stop the loop from running.
